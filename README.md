# Hey there Shaunak Soni Here !!

### About Me

MS Computer Science student at Northeastern University (expected May 2027) and B.Tech IT graduate from Dharmsinh Desai University (2025). I build AI systems that solve real problems, from retrieval pipelines and local LLM tools to full-stack web apps.

Currently Vice President of NU Launch Labs, Northeastern's 500+ member student incubator, where I help 20+ teams turn ideas into working projects.

Experience:

- **Institute for Plasma Research** (Web Development Intern, Dec 2024 – Apr 2025): built the backend of a Lab Inventory Management System, migrated it from PHP to JavaScript and Next.js, and integrated the institute's LDAP server
- **Techplement** (Web Development Intern, May 2024 – Aug 2024): built an e-commerce store's React dashboard and worked on its payment gateway with a seven-person intern team

What I have built:

- **JARVIS**: modular voice-driven AI assistant with an intent-based orchestrator across nine modules and an LLM fallback cascade (Ollama → LM Studio → cloud → offline)
- **RAG Research Q&A**: question answering over arXiv papers with SentenceTransformers, FAISS, and Flan-T5
- **LLM Log Triage Pipeline**: hackathon tool that turns raw HDFS logs into validated JSON triage reports with a local Gemma 2B model
- **Weekend Gap Prediction**: collaborative ML study comparing XGBoost, logistic regression, and an LSTM on equity market gaps under walk-forward validation
- **Enhanced HouseGAN++**: floor plan generation with spectral normalization and self-attention
- **Nirogya**: healthcare app for appointments and prescriptions with React, Node.js, MongoDB, and JWT auth
- **Employee Management System**: Spring Boot REST API with a React frontend

Technical Focus: machine learning, LLM applications, computer vision, full-stack development, and cloud architecture on AWS.

Certifications: Machine Learning (Coursera) | Google Foundations: Data, Data, Everywhere | AWS Cloud Foundations | AWS Cloud Architecture
